# 📊 Sales & Customer Analytics using Excel

## 📌 Project Overview

This project analyzes sales and customer data using **Microsoft Excel** to identify business trends, customer behavior, product performance, and key sales insights.

The project demonstrates practical **data cleaning, data analysis, PivotTables, formulas, visualizations, and dashboard creation** skills relevant to a Data Analyst role.

---

## 🎯 Business Objective

The objective of this analysis is to answer key business questions such as:

* Which products and categories generate the most sales?
* Which regions perform the best?
* How do sales change over time?
* Who are the top customers?
* Which products contribute most to overall performance?
* What trends and patterns can help support business decisions?
